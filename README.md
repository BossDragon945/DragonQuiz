- 正確答案只存在你的 Google 試算表,批改由 Apps Script 進行,**按 F12 也看不到答案**
- **每題限時**,時間到自動交出;不能回上一題
- 作答中切換 App / 分頁 / 視窗,該題直接算錯;題目文字無法複製
- 每個人的題目與選項順序都不同

> 但**正解從頭到尾不會離開伺服器**,批改也在伺服器端做,所以沒辦法直接得知
> 答案或偽造分數。家族同樂足夠,不適合需要嚴格防弊的正式考試。

- 作答紀錄存在**你自己的 Google 帳號**裡,沒有第三方服務
- 筆數沒有上限

## 🚀 首次設定(只需做一次)

分成四步:在 Google 那邊建好接收端與題庫,再把網址填回這個專案。

> 💡 四步全部做完才會動。只做到步驟 3 就打開網站,會看到「測驗載入失敗
> ─ 題庫是空的」,那是正常的,把步驟 4 做完就好。

### 步驟 1:建立試算表與 Apps Script

1. 到 [Google 試算表](https://sheets.google.com) 建立一個**新的空白試算表**,
   名字隨意(例如「家族測驗作答紀錄」)
2. 在該試算表上方選單點 **擴充功能 → Apps Script**
3. 把編輯器裡原有的內容**全部刪掉**,改貼上本專案
   [`apps-script/Code.gs`](apps-script/Code.gs) 的完整內容
4. 按 💾 儲存

### 步驟 2:部署成網頁應用程式

1. 在 Apps Script 編輯器右上角點 **部署 → 新增部署作業**
2. 齒輪圖示選 **網頁應用程式**
3. 設定如下:

   | 欄位 | 要選的值 |
   |---|---|
   | 執行身分 | **我** |
   | 具有應用程式存取權的使用者 | **任何人** |

   > ⚠️ 「任何人」是必要的 —— 家族成員不需要登入 Google 就能作答。
   > 這不會讓別人看到你的試算表,他們只能送出資料,讀不到內容。

4. 按 **部署**,第一次會要求授權,依畫面同意即可
   (中途若出現「Google 尚未驗證這個應用程式」,點
   **進階 → 前往「專案名稱」(不安全)** 繼續,那是你自己寫的程式)
5. 複製最後給你的**網頁應用程式網址**,格式像:
   ```
   https://script.google.com/macros/s/AKfycb.....輸入一長串..../exec
   ```

### 步驟 3:填回專案

打開 [`config.js`](config.js),把網址貼進 `appsScriptUrl`:

```js
appsScriptUrl: "https://script.google.com/macros/s/AKfycb..../exec",
```

commit 並 push,等 GitHub Pages 重新建置(約一分鐘)。

### 步驟 4:把題目填進題庫

回到步驟 1 建立的那份試算表,你會看到程式自動多開了一個
**「題庫」**工作表,標題列已經幫你填好了。

最快的做法:打開本專案的 [`題庫範例.tsv`](題庫範例.tsv),
**全選複製 → 貼到「題庫」工作表的 A1 儲存格**。
試算表會自動把 tab 分隔的內容分欄。

> 沒看到「題庫」工作表的話,先用瀏覽器打開一次步驟 2 拿到的 Apps Script
> 網址,程式會在那時候把工作表建出來。

各欄位的填法見下一節。

## ✅ 確認設定成功

用瀏覽器直接打開步驟 2 拿到的 Apps Script 網址,應該看到:

```json
{"ok":true,"type":"info","message":"測驗接收端運作中","total":5,"timeLimit":15,"open":true,"window":"(未設定,隨時可作答)"}
```

`total` 就是題庫裡的題數(貼了範例題庫的話是 5),`timeLimit` 是每題秒數,
`open` / `window` 是目前能不能作答與開放時間(見下方「活動開放時間」)。
**回應只有題數和限時,不含任何題目或答案** —— 這正是答案藏在伺服器端的證明。

看到 `{"ok":false,"error":"題庫是空的..."}` 代表步驟 4 還沒做。

## ✏️ 修改題目

題目放在試算表的 **「題庫」** 工作表(第一次打開網頁或 Apps Script 網址時會自動建立標題列)。
每一列一題:

| 題目 | 選項A | 選項B | 選項C | 選項D | 選項E | 選項F | 正解 | 解說 | 限時秒數 | 題目日文 | 題目越南文 | 題目英文 | 選項日文 | 選項越南文 | 選項英文 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 題目文字 | 選項一 | 選項二 | 選項三 | 選項四 | | | B | 解說文字(可留空) | (可留空) | (可留空) | (可留空) | (可留空) | (可留空) | (可留空) | (可留空) |

- `正解` 填**字母** A~F
- 選項 2 到 6 個都可以,但要從 A 開始連續填,中間不能空格
- `解說` 在 `SHOW_ANSWERS` 開啟時才會顯示在結果頁,可留空
- `限時秒數` 留空就用預設值(`Code.gs` 的 `DEFAULT_TIME_LIMIT`,預設 15 秒)
- `題目日文` / `題目越南文` / `題目英文` 可留空,有填的會依日、越、英的順序顯示在題目下方三欄都留空就跟以前一樣
- `選項日文` / `選項越南文` / `選項英文` 可留空。每個語言一格,把各選項的翻譯**依 A、B、C… 的順序用 `|` 隔開**,例如 `4人、1人600 | 6人、1人800 | 8人、1人1000`;翻譯數量必須跟選項數量一樣,否則會顯示錯誤。有填的會顯示在各選項下方

改完試算表就立刻生效,**不需要 push,也不需要重新部署 Apps Script**。

> 已經開始作答的人不受影響,會用他開始時的題目答完。
> 題數**增加**後,「作答紀錄」會自動補上新的標題欄位與所需欄位,舊資料不受影響;
> 題數減少時不會刪掉多出來的欄位,那些欄位之後會留白。

可以拿 [`題庫範例.tsv`](題庫範例.tsv) 當格式範本 —— 直接改裡面的文字,
再整份貼回「題庫」工作表的 A1 就好。

## ⏰ 活動開放時間

試算表裡會自動建立一個 **「設定」** 工作表:

| 項目 | 值 |
|---|---|
| 開始時間 | 例如 `2026/11/15 20:00`,留空 = 不限制 |
| 結束時間 | 例如 `2026/11/15 22:00`,留空 = 不限制 |

- 時間外打開網頁會看到「活動尚未開始」或「活動已經結束」,**連題目都不會發出**
- 只擋「開始作答」:在結束前按下開始的人,過了結束時間仍然可以答完交卷
- 時區以試算表的時區為準(檔案 → 設定)
- 改完立刻生效,不需要重新部署

## 🔒 每個人只能作答一次

分兩層擋:

- **伺服器端(以姓名為準)**:「作答紀錄」裡只要出現過同一個名字,
  不論有沒有交卷,都不能再用這個名字作答。中途關掉頁面也算用掉一次,
  避免「看到難題就關掉重來」
- **瀏覽器端**:作答過的瀏覽器會記住,再打開就直接顯示「已經作答過了」

姓名是自己填的,換個名字或換台裝置、開無痕視窗就能再答一次,
這部分只能靠事後看紀錄抓。

要讓某個人重答:到「作答紀錄」刪掉(或改掉)他那幾列的姓名,
再請他清掉瀏覽器資料或換個瀏覽器。

### 辦下一場

1. 把 [`config.js`](config.js) 的 `round` 改成不同的值(例如 `"2"`),
   push 之後所有人的瀏覽器記錄就會失效
2. **清空「作答紀錄」工作表**(或另開一份新的試算表重新部署),
   否則同名的人仍然會被上一場的紀錄擋住

## ⚙️ 其他設定

[`config.js`](config.js) 裡還有:

| 設定 | 說明 |
|---|---|
| `title` / `subtitle` | 頁面標題與副標題 |
| `requireName` | 設為 `false` 則不要求輸入名字(伺服器會全部記成「(未具名)」,第一個人答完其他人就都被擋住,建議保持 `true`) |
| `round` | 場次代號,見上方「辦下一場」 |

[`apps-script/Code.gs`](apps-script/Code.gs) 最上方:

| 設定 | 預設 | 說明 |
|---|---|---|
| `DEFAULT_TIME_LIMIT` | `15` | 每題預設限時(秒) |
| `GRACE_SECONDS` | `5` | 網路延遲寬限,超過「限時 + 寬限」才算逾時 |
| `SHUFFLE` | `true` | 每人打亂題目與選項順序 |
| `SHOW_ANSWERS` | `false` | 交卷後是否顯示正解與解說 |

> **改了 Code.gs 之後**:貼回 Apps Script 編輯器並儲存,再到
> **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**,網址不會變。

## 🕵️ 作答紀錄怎麼看

「作答紀錄」工作表每次作答一列:

| 欄位 | 說明 |
|---|---|
| 狀態 | 打開網頁就先寫一列「作答中」(姓名暫記「(未開始)」,按下開始才補上名字),交卷後改成「完成」。有名字卻停在「作答中」代表中途放棄;姓名是「(未開始)」的只是開了頁面沒作答 |
| 答對題數 | 答對題數 / 總題數,例如「3 / 6」 |
| 得分 | 答對的題數(每題 1 分) |
| 離開畫面 | 作答中切到別的 App / 分頁 / 視窗的次數(該題算錯) |
| 逾時 | 超過限時沒交的題數 |
| 第 N 題作答 / 第 N 題正解 / 第 N 題 / 第 N 題秒數 | 選了什麼、正確答案是什麼、○ ✕ 逾時 離開、花了幾秒 |

題號是依題庫順序,不是作答者看到的順序。

### 排行榜

試算表裡的「排行榜」工作表會依**得分(分數)高到低**即時列出所有「完成」的人,
同分的並列名次、先開始的排前面。它是用公式從「作答紀錄」算出來的,
有人交卷就自動更新,不用任何操作。只有能開啟試算表的人看得到,作答網頁不會顯示。
它只在「作答紀錄」標題列需要建立或更新時(首次部署、新增題目數、升級欄位)自動建立一次;
不小心刪掉的話,需要把「作答紀錄」第 1 列清空,下次有人作答就會重建。

可疑的跡象:同一個名字很多列「作答中」(先開一輪偷看題目)、
每題都拖到接近限時才交卻幾乎全對(可能在查資料或問 AI)。

## ⚠️ 重要提醒

- **沒辦法完全防止用 AI 作弊。** 拿另一支手機拍螢幕問 AI,網頁偵測不到。
  最有效的做法是出**只有家族成員才知道**的題目(網路上查不到),再搭配短限時。
- 離開畫面偵測、禁止複製、作答秒數都是在瀏覽器端做的,懂技術的人可以繞過或竄改;
  但正解和計分在伺服器,看不到也改不了。
- `SHOW_ANSWERS` 開啟時,先交一次卷就能看到全部答案。
- 姓名是自己填的,沒辦法驗證身分。
- 桌機上點到網址列或其他視窗也會被當成「離開畫面」。

家族同樂綽綽有餘,但仍**不要拿來做需要嚴格防弊的正式考試**。
